## 🛠️ Installation

- **Clone the Repository**

  ```bash
  git clone https://github.com/mustafagenc/homepage.git
  ```

- **Navigate to the Directory**

  ```bash
  cd homepage
  ```

- **Install Dependencies & Start Developement Server**

  ```bash
  yarn & yarn dev
  ```
